You are helping build a research dataset. For each English request below, write it in 4 Bangla forms. Same meaning in all 4. Every value under "Must keep" must appear.

FORMS:
1. bn_native: Natural everyday Bangla in Bangla script, the way a person would really ask an assistant (not bookish). Write ALL names in Bangla script too (টোকিও, not Tokyo).
2. bn_roman: The bn_native sentence written word for word in English letters, the way a young Bangladeshi types on WhatsApp/Messenger. Casual phonetic spelling for Bangla words, no diacritics. BUT names of people, places, brands, websites and abbreviations are written in their normal English spelling, as people really type them (Apple Inc, Los Angeles, NBA, Foodnetwork.com), never spelled out phonetically.
3. bn_mixed: Natural Banglish chat: Bangla grammar in English letters, with English words where a Bangladeshi would really use them.
4. bn_partial: Same as bn_native, but the "Must keep" values written in English letters exactly as they appear in the English request.

RULES:
- Write like a real person asking an assistant, not a word-for-word translation.
- Do not add or remove any information.
- NO EXTRA ANSWER: a value may appear only in the form and wording the English request uses. If English writes a number as a word ("three"), keep it a word (তিন / tin / three). If English writes digits, use English digits 0-9. Never change capital letters, date formats, or words to match the "Must keep" list. Never add a word that is not in the English request.
- Output ONLY a tab-separated table with columns: item_id, bn_native, bn_roman, bn_mixed, bn_partial
- One row per item, no extra text.

EXAMPLE:
English: What is the weather in Dhaka today? | Must keep: city = Dhaka
